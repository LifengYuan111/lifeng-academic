# Banner design options

Both banner options were created with the built-in image generation workflow using `source_inputs/profile.png` as an identity-preserving reference. Neither image contains text; the website will render accessible HTML hero copy over the reserved negative space.

## Option A — River Basin Portrait

- File: `banner-a-river-basin.png`
- Size: 1983 × 793 px
- Composition: portrait on the left; natural river-basin valley and subtle drainage-network overlay; copy space on the right.
- Intended tone: natural, approachable, field-science focused.

Prompt summary: Preserve the exact person, glasses, face, apparent age, clothing and lapel pin; place the waist-up portrait on the left third of a realistic river-basin landscape; use deep river blue, slate and muted teal; leave calm negative space on the right; no text, logos or watermark.
